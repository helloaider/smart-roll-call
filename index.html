✏️ 编辑器
🎲 随机点名
⚖️ 均衡抽取 优先从被点次数最少的同学中随机抽取，保证机会均等；姓名滚动定格后座位高亮，若已开启学生介绍则自动弹出介绍卡片；本轮所有人都被点过后自动进入下一轮，并在屏幕上方弹出「第 N 轮完成」提示
🌐 全员随机 不考虑被点次数，每次从全班完全随机抽取；定格后同样高亮座位并自动弹出介绍卡片（需已开启），无轮次概念，适合需要重复点名的场景
🔢 轮次计数 顶部「第 N 轮 · 还剩 X 人」实时显示当前轮进度，仅均衡抽取模式下有意义；全员随机不影响轮次
⏳ 操作节奏 滚动期间按钮禁用，定格后即可继续；再次点击任意抽取按钮时，上一次的介绍卡片和结果提示会立即关闭
💾 点名记录、轮次计数均自动保存，刷新页面后不丢失
✋ 手动点名
👆 双击座位 直接标记该学生为已点名，座位高亮，姓名更新到顶部，若已开启学生介绍则自动弹出介绍卡片
↩️ 再次双击 弹出确认框，确认后取消点名记录，座位恢复未点状态
🖱️ 右键座位 弹出菜单，可查看或编辑该学生的介绍 / 备注；备注仅教师可见，有备注的座位左上角显示红点；菜单中还可直接切换该学生的「今日排除」状态
🎯 更多抽取（···）
🔢 批量点名(抽N人) 一次抽取多人（可配置 1～50 人），支持全班、指定小组两种抽取范围，每种范围均可选择均衡抽取（优先被点少的学生）或完全随机；滚动定格后所有被选座位同时高亮，点「确认计入记录」才写入统计，点「关闭」则放弃本次结果
🎲 随机抽取小组 从所有小组中随机抽出一组，滚动定格后弹出「抽到：第 X 组」及成员名单；不触发学生介绍，仅展示小组信息
🎯 组内随机抽(抽1人) 选择目标小组，弹窗列表显示每组成员预览和当前轮次/剩余候选人数；点击行选中小组后，通过底部按钮选择模式：均衡抽取优先从本组被点次数最少的组员中随机抽，本轮全员点完后自动进入下一轮并弹出提示；完全随机从组内所有有效成员中纯随机抽，不计轮次；定格后座位高亮，若已开启学生介绍则自动弹出介绍卡片，点名记录同步计入统计
🏆 抽小组出场顺序 随机打乱所有小组的出场顺序，适合答辩、汇报、展示等任何需要排序的场景；前三名用金银铜牌标注，显示每组成员名单；可点「重新抽」反复抽直到满意，点「复制结果」将顺序复制到剪贴板
📝 指定名单随机抽 手动输入任意姓名（每行一个）后抽取；若抽中的姓名在座位表中存在则高亮对应座位并弹出介绍卡片；若不在座位表中则仅显示姓名。支持将常用名单保存为命名名单，下次直接加载
🚫 今日排除 右键座位 → 今日排除，该学生本次不参与任何随机抽取；被排除的座位半透明显示并带 🚫 标记；姓名区上方出现提示条，点击可批量恢复；排除状态仅当前会话有效，刷新后自动清空
✅ 考勤/签到 「···」→ 考勤/签到模式，以座位表布局展示全班学生，点击格子循环切换状态：到课 → 缺席 → 请假；右侧常驻侧边栏实时显示缺席/请假名单，点击名单中的「↩ 切换」可快速改回到课；顶部操作栏可一键「全部到课」或「全部缺席」；底部实时汇总人数，点「保存考勤记录」写入记录；考勤数据不计入被点次数，在统计页以聚合行独立展示
🎨 显示偏好配置
🎛️ 打开方式 ☰ → 显示偏好配置，在弹窗中统一管理所有显示选项，点「保存」后实时生效并自动记住；点「取消」放弃本次修改
🔢 被点次数 开启后每个座位右上角显示该学生累计被点次数角标
🏅 班委标记 开启后姓名下方显示彩色下划线：红色 = 班长，绿色 = 组长；需在编辑器中为学生设置班委角色后生效
🎨 小组背景 开启后同组学生座位显示相同背景色，方便区分；需先在编辑器中配置小组
📖 学生介绍 开启后每次点名定格时自动弹出介绍卡片；卡片出现在姓名右侧，底部进度条倒计 25 秒后自动消失，有图片时右上角出现放大按钮
🖼️ 学生照片 将照片放入 student_photos/ 目录，文件名与学生姓名一致（如 张三.jpg），支持 jpg / png / webp，点名时自动显示
🔄 座位视角 教师视角 / 学生视角切换；学生视角下座位表整体左右翻转，适合投影给学生看时使用
⚙️ 点名管理
🏫 班级管理 ☰ → 管理班级列表，支持同时维护多个班级的座位配置与点名记录；可「＋ 新建班级」、切换当前班级、改名或删除；切换班级时自动保存当前记录并重新加载页面；顶部班级名称徽标也可直接点击打开此弹窗
🕐 本次记录 ☰ → 查看本次记录，以轻量浮层快速查看当天所有点名结果（按时间倒序），无需离开当前页面
🚫 排除名单 ☰ → 管理排除名单，查看当前所有被排除的学生，可逐个点击「恢复」或「全部恢复」
🗑️ 清空记录 一键清除本轮所有点名记录及轮次计数，⚠️ 操作不可撤销
📤 导出记录 将所有点名数据保存为 Excel 文件，方便存档或换设备使用
📥 导入记录 从之前导出的 Excel 文件恢复数据，支持跨设备迁移历史记录；导入时会自动比对当前座位表，不在当前班级名单中的姓名会被过滤忽略，不会串班，系统会提示被忽略的学生名单
📊 数据统计
📋 点名统计 查看每位学生累计被点次数，支持升序 / 降序排列，可按时间范围筛选；被点次数明显偏高/偏低的学生自动标记 ⚠️偏高 / ⚠️偏低
🕐 点名记录 按时间顺序查看每次点名详情，含抽取范围列，可悬停查看本次参与随机的完整名单；支持按时间排序和范围筛选
📈 趋势图 折线图展示被点次数随时间的变化；顶部下拉可切换全班合计或单个学生，联动日期范围筛选
🗓️ 考勤统计 查看所有考勤记录明细（每次考勤的到课/缺席/请假人数及异常学生）和学生出勤汇总（缺席次数、请假次数、出勤率）；出勤率 ≥90% 显示绿色，75–90% 黄色，低于 75% 红色；联动日期范围筛选
📤 导出统计 将数据导出为 Excel，包含「点名统计」（各学生被点次数）、「点名记录」（每次点名详情）、「课堂报告」（今日点名流水 + 全员被点统计 + 公平性预警 + 统计摘要）三个 Sheet；有考勤数据时额外附加「考勤明细」和「出勤汇总」；联动日期范围筛选
💾 统计数据跨会话保存，刷新页面后不丢失
✏️ 编辑器（builder.html）
🖥️ 打开编辑器 ☰ → 编辑座位信息，在 builder.html 中编辑座位表、班级信息、小组、学生介绍等所有配置；也可直接双击打开 builder.html
📥 导入配置 支持两种方式：① 从之前生成的点名器 HTML 文件导入，完整还原上次配置；② 从 Excel 导入（按样表格式），可点「下载样表」获取参考格式，支持座位表、学生介绍、小组颜色一并导入
📋 基础信息
🏷️ 班级标题 显示在座位表顶部的标题文字，如「xx学校-xx教室座位表」
💬 班级口号 显示在座位表标题下方的一行小字，可填班级口号、座右铭等
🌐 网页标题 浏览器标签页上显示的文字，默认「智能课堂点名器」
🖼️ 选项卡图标 浏览器标签页上的小图标（favicon），可上传班级或学校 Logo，建议正方形 PNG/JPG，64×64 像素
🪑 座位表编辑
📐 预设模板 提供标准教室、含过道、U型、研讨型等多种常见布局，选择后一键生成座位结构，只需填写学生姓名即可
➕ 增删行列 通过「+ 行」「- 行」「+ 列」「- 列」按钮动态调整座位表大小，最大支持 20 行 × 30 列
🔲 格子类型 每个格子左侧有类型下拉：学生（填姓名参与点名）、空格（占位，不参与点名）、过道（细窄分隔列）、讲台（跨列展示讲台区域）
🏅 班委角色 每个学生格右侧有角色下拉：普通 / 班长（红色下划线）/ 组长（绿色下划线）；需在显示偏好中开启「班委标记」后可见
📋 批量填入 展开「批量填入学生姓名」面板，粘贴姓名列表（每行一个，或逗号/分号分隔），点「填入座位表」按列优先顺序自动填入所有学生格
↕️ 拖拽排序 直接拖拽格子可与其他格子交换位置；编辑姓名输入框时不触发拖拽
👫 小组 / 介绍
👫 小组管理 新增小组后将学生拖入对应组，同组座位显示相同背景色；「↻ 刷新未分组学生」可同步座位表姓名变动；导入 Excel 时若单元格有背景色会自动建组
📖 学生介绍 为每位学生填写介绍文字和备注；点「↻ 从座位表自动填入姓名」可快速生成条目；介绍在点名后弹出（需开启），备注仅教师可见
🚀 应用 / 导出
⬇️ 生成 HTML 将当前配置打包成独立 HTML 文件下载，双击即可使用，建议与 builder.html 放在同一目录
📊 下载 XLSX 导出包含座位表、学生介绍及备注的 Excel 文件，方便备份或二次编辑后重新导入
↩️ 立即应用 编辑完成后点「↩ 立即应用」，配置直接写入点名器，无需下载重新打开；需从点名器「✏️ 编辑座位信息」跳转，或两个文件在同一目录下
🗑️ 清空重来 清除编辑器中所有已填内容，回到空白状态；不影响点名器已保存的数据
🔁 恢复默认 ☰ → 恢复默认配置，将清除全部本地数据（含座位配置、备注、点名记录及所有偏好设置），⚠️ 操作不可逆，请提前导出备份
💾 所有配置、介绍内容、主题及偏好设置均自动保存在浏览器本地，关闭或刷新页面后不丢失  ·  🌐 建议使用 Chrome / Edge 等现代浏览器
