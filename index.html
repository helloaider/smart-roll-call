📋 智能课堂点名器 · 使用说明

✕
🎲 随机点名
⚖️ 均衡抽取 优先从被点次数最少的同学中随机抽取，保证机会均等；本轮全部点完后自动进入下一轮并弹出提示
🌐 全员随机 不考虑被点次数，每次从全班完全随机抽取，适合需要重复点名的场景
🌀 姓名滚动约 1 秒后定格，对应座位同步高亮闪烁
⏳ 滚动期间按钮禁用，等待定格后即可继续点名
✋ 手动点名
👆 双击座位 直接标记该学生为已点名，座位高亮显示，姓名同步更新到顶部
↩️ 再次双击 弹出确认框，确认后取消点名记录，座位恢复未点状态
🖱️ 右键座位 弹出菜单，可查看或编辑该学生的介绍 / 备注；备注仅老师可见，有备注的座位左上角显示红点
🎨 显示偏好
🎛️ 打开方式 ⚙️ → 显示偏好配置，在弹窗中统一管理所有显示选项，修改后实时生效并自动记住偏好
🔢 被点次数 开启后座位右上角显示累计被点次数
🏅 班委标记 开启后姓名下方显示彩色下划线：红色 = 班长，绿色 = 组长
🎨 小组背景 开启后同组学生座位显示相同背景色，关闭后恢复统一配色
🔄 座位视角 教师视角 / 学生视角切换，学生视角下座位表整体左右翻转
☀️ 主题切换 深蓝 / 暗黑两种主题，切换后自动记住偏好
📖 学生介绍
🔛 开启方式 ⚙️ → 显示偏好配置 → 学生介绍，开启后每次点名自动弹出介绍卡片
📍 显示位置 卡片出现在姓名右侧，约 20 秒后自动消失；有图片时右上角出现放大按钮，点击可居中放大查看
🖼️ 学生照片 将照片放入 student_photos/ 目录，文件名与学生姓名一致（如 张三.jpg），支持 jpg/png/webp 等格式，点名时自动显示
✏️ 编辑内容 右键座位 → 查看介绍，点击「编辑」修改，保存后立即生效
⚙️ 点名管理
🗑️ 清空记录 一键清除本轮所有点名记录，⚠️ 操作不可撤销
📤 导出记录 将所有点名数据保存为 Excel 文件，方便存档或换设备使用
📥 导入记录 从之前导出的 Excel 文件恢复数据，支持跨设备迁移历史记录
📊 数据统计
📋 点名统计 查看每位学生的累计被点次数，支持按表头次数排序
🕐 点名记录 按时间顺序查看每次点名详情，同样支持按表头时间排序
💾 统计数据跨会话保存，刷新页面后不丢失
✏️ 编辑器（builder.html）
🖥️ 打开编辑器 ⚙️ → 编辑座位信息，在 builder.html 中编辑座位表、班级信息、小组、学生介绍等所有配置
📥 导入配置 支持从之前生成的点名器 HTML 文件导入，或从 Excel 导入（网页配置 / 座位表 / 学生信息）
👫 小组管理 为学生分配小组后，同组座位显示相同背景色；导入 Excel 时若有背景色会自动建组
⬇️ 生成 HTML 将当前配置打包成独立 HTML 文件，双击即可使用，建议与 builder.html 放在同一目录
📊 下载 XLSX 导出包含座位表和学生介绍的 Excel 文件，方便备份或二次编辑后重新导入
↩️ 立即应用 编辑完成后点击「↩ 立即应用」，无需刷新即时生效；需从点名器「✏️ 编辑座位信息」跳转，或两个文件在同一目录下
🔁 恢复默认 ⚙️ → 恢复默认配置，将清除全部本地数据，⚠️ 操作不可逆，请提前导出备份
💾 点名记录、介绍内容、主题及所有偏好设置均自动保存在浏览器本地，关闭或刷新页面后不丢失  ·  🌐 建议使用 Chrome / Edge 等现代浏览器以获得最佳体验
